# Aster 聊天翻译

聊天翻译工具。解压后双击 `Aster聊天翻译.exe` 即可运行，无需安装。

两种翻译模式，设置里可切换：

- **AI 模型**（默认）：截图交给视觉模型直接读，译文完整准确；需要联网 + API Key。
- **本地词库**：用内置术语表逐词对照，不联网、不需要 Key、不花钱；
  只能看关键词大意（中英混杂、语序可能乱），适合断网或只想扫一眼的时候。

> 当前只适配《魔兽世界》的聊天格式，其它游戏暂不支持。

## 首次使用

1. 双击 exe，右下角托盘出现星形图标
2. 右键托盘 → 设置
3. 「翻译区域」→ 重新框选，框住聊天窗口
4. 选「翻译模式」：AI 模型（需要 Key）或 本地词库（不需要 Key）；
   用 AI 的话在同一页填 API Key（支持 DeepSeek 等 OpenAI 兼容接口），点保存
5. 按下快捷键实时翻译；另一个快捷键看上次翻译（默认小键盘 `+` / `−`，可在设置里改）

> AI 模式需要联网；本地词库模式完全离线。
> 本地词库没收录的词会记到 `glossary_miss.log`（只记词和次数，不记聊天内容），方便后续补词。

## 注意

- 只适配《魔兽世界》的聊天格式，其它游戏暂不支持
- **AI 模式**会把截图发到你配置的接口（含其他玩家名字与聊天内容），介意的话请用本地词库模式或勿使用
- **本地词库模式不联网**，只在内存里做 OCR + 词表替换
- API Key 明文保存在 config.json，请勿把整个文件夹发给别人
- 需要 WebView2 运行时（Win10/11 一般已自带）
